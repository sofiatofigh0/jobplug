JobPlug

Tracks every job you apply to, writes it to Google Sheets, and watches Gmail for interview invites.

First-time setup

Three steps, once.

  1. Create a Google Cloud project and enable the Google Sheets API and Gmail API.
  2. Make an OAuth client. Easiest path is an Chrome App client using this extension's ID () — paste it into manifest.json under oauth2.client_id. On Brave/Edge, or if you would rather not pin the extension ID, switch the Sign-in method below to Browser redirect and paste a Web-application client ID instead.
  3. Click Connect Google. A spreadsheet is created for you automatically.

Full walkthrough with screenshots-worth-of-detail is in SETUP.md in the repo.

Spreadsheet

One spreadsheet with three tabs: Applications, Dashboard, and Email Log.

Paste an existing ID to adopt a sheet you already have, or leave blank and one is created for you. The ID is the long string in the URL between /d/ and /edit.

Gmail watching

Read-only. JobPlug searches only for mail plausibly related to a company you applied to, then classifies it as an acknowledgement, assessment, interview invite, offer or rejection.

Watch Gmail for replies Turn this off and statuses stay whatever you set by hand.

Resume versions

Map filenames to readable names so the dashboard can tell you which resume actually gets replies. Matching is case-insensitive substring, or a regular expression.

Company enrichment

Stage, valuation, total raised and headcount are read off the job page itself whenever the company states them. Most postings don't, so those cells will often be blank until you fill them in — the popup and the sheet are both editable. If you have access to a funding data API, point JobPlug at it and it will fill the gaps automatically.

Call an enrichment API for missing company data Sends only the company name and domain.

{domain} and {name} are substituted.

Expected response: JSON with any of stage, valuation, totalRaised, lastRound, lastRoundDate, headcount, industry.

Local data

Applications live in this browser and in your spreadsheet. Clearing local data does not touch the spreadsheet.
